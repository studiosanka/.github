# How we work

This applies to every Studio Sanka repository that does not have its own `CONTRIBUTING.md`.

## Pull requests

Our repositories are maintained by Studio Sanka members. **We are not accepting pull requests or outside contributions at this time.**

## Issues are very welcome

Found a bug, hit a problem while building, or have a question or an idea? Open an issue in the repository it is about, and pick the form that fits. (The website's own repository is private, so for a problem with the website, open an issue in the [sixeyes repository](https://github.com/studiosanka/sixeyes/issues) and say it is about the website.) We read everything, though we cannot promise to answer every message.

A good issue says:

1. **What you were trying to do.** (For example "flash the firmware to the Base board".)
2. **What happened.** Copy any error message exactly. A photo helps a lot for hardware.
3. **What you expected.**
4. **What you have already tried.**
5. **What you are using:** computer or phone, operating system, which version or commit.

You do not need to know the answer or write it technically. "It didn't work and here is a photo" is a fine start.

If an arm moved when it should not have, or did not stop when it should, say so at the top. Switch it off at the power supply first, and see [SECURITY.md](SECURITY.md).

## Using our designs

The licences and what you must do if you build or sell something from our designs are in the [sixeyes repository](https://github.com/studiosanka/sixeyes/blob/main/CONTRIBUTING.md). In short: the designs are free to use, and if you sell something made from them you must credit Studio Sanka.

## Behaviour

Everyone taking part follows our [code of conduct](CODE_OF_CONDUCT.md). Many of the people here are students, so please be kind and patient.
